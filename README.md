# Gemini 英会話トレーナー

自由に入力した場面でGeminiと英会話を練習できる、インストール可能なPWAです。研究論文・学会ポスターのPDFを使う従来の練習モードも残しています。

## 主な機能

- 日本語または英語で、練習したい会話場面を自由入力
- Geminiによる会話、発話ごとの英文添削、日本語の修正解説
- ボタンを1回押して録音開始、もう一度押すまで継続し、停止後にGeminiが文字起こし
- 答え方が浮かばないときのヒント候補
- Gemini TTSによる自然な読み上げ（失敗時は端末の英語音声へ自動フォールバック）
- 任意のタイミングで終了し、良かった点・改善点・使える表現を表示
- 表現帳への保存、手動追加、読み上げ、復習
- 表現帳JSONをAndroid共有シートへ渡し、端末やGoogle Driveへ保存
- 端末またはGoogle DriveのJSON/TXTをシステムファイル選択画面から読み込み
- ホーム画面へ追加できるPWA、アプリ画面のオフライン起動

## 使い方

1. GitHub PagesのURLをHTTPSで開きます。
2. Google AI Studioで取得したGemini APIのAuth keyと、会話に使うモデル名を入力します。
3. 場面を入力して「この場面で会話をはじめる」を押します。
4. テキストまたはマイクで返答します。マイクは開始と停止をそれぞれ1回タップします。
5. 「終了する」を押すとセッションレポートが作られます。

AndroidではChromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選べます。表現帳の「保存先を選んで保存」はAndroidの共有先一覧または保存先選択画面を開くため、そこでGoogle Driveまたは端末内の保存先を選んでください。保存先を選ばない限りスマホへ自動ダウンロードしません。Driveとの自動同期やGoogle OAuthは使用しません。

## APIとプライバシー

- APIキー、モデル名、表現帳はブラウザ内に保存されます。
- 表現帳の共有ファイルにAPIキー、会話全文、録音データは含まれません。
- APIキーをURLへ付けず、`x-goog-api-key` ヘッダーでGoogleへ送信します。
- 静的PWAでは利用者自身のブラウザからGoogleへ直接通信するため、DevTools等からAPIキーを完全に秘匿することはできません。公開配布サービスとして運用する場合は、認証・利用制限を備えたサーバー側プロキシを用意してください。
- Service Workerはアプリ本体だけをキャッシュし、Gemini API通信、APIキー、録音、会話内容はキャッシュしません。

## ローカル確認

マイク、Service Worker、共有機能にはHTTPSまたはlocalhostが必要です。

```bash
python -m http.server 8000
```

その後、`http://localhost:8000/` を開きます。
